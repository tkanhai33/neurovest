# Final Start Decision

NeuroVest is approved to enter Phase 1 — Repository Skeleton.

Allowed:
- folders
- README files
- contract docs
- .env.example
- FastAPI health shell
- PostgreSQL placeholders
- frontend folders
- tests/certification folders

Forbidden:
- trading logic
- broker execution
- strategy scoring
- risk engine logic
- autonomous loops
- real order paths
- paid provider dependency
- complex UI systems
